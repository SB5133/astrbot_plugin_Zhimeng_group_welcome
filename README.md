# 群欢迎（astrbot_plugin_Zhimeng_group_welcome）

> AstrBot 插件（原 astrbot_plugin_hello-bye，由 稚梦/SB5133 接手维护）


## 🐔 使用说明
**在新成员进群或者老成员退群时，发送一条信息提示！支持每个群单独配置。**

### v1.2.0更新（稚梦接手版）
- :sparkles: 每个群可单独配置：欢迎/退群/踢人的文字和图片，群配置优先于全局配置
- :sparkles: 新增群管理命令（均为管理员权限，在群内使用）：
  - `设置欢迎消息` / `设置欢迎图片`：设置本群入群提示
  - `设置退群消息` / `设置退群图片`：设置本群退群提示
  - `设置踢人消息` / `设置踢人图片`：设置本群被踢提示
  - `开启本群提醒` / `关闭本群提醒`：单独开关本群的入退群提醒
  - `查看本群配置`：查看本群所有单独配置
  - `清除本群配置`：清除本群单独配置，恢复使用全局配置
- :arrow_up_down: 数据目录由 `data/hello-bye` 迁移到 `data/zhiMeng_hello-bye`（旧数据可手动把 `data.json` 拷过来）
